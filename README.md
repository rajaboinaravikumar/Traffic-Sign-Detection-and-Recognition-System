
 
# 🚀 AI-Powered Traffic Sign Detection and Recognition System

An intelligent deep learning–based system that automatically detects and classifies traffic signs from real-time road images and videos. The project leverages Convolutional Neural Networks (CNNs) and computer vision techniques to enhance road safety and support autonomous driving and driver-assistance systems.


## ✨ Key Features

* 🔍 Real-time traffic sign detection and recognition
* 🧠 Deep Learning (CNN) based classification
* 🚦 Detects signs like Stop, Speed Limit, No Entry, etc.
* ⚡ Faster decision support for drivers and smart vehicles
* 🛡️ Reduces human error and improves road safety
* 📊 Robust performance under varying road conditions



## 🧰 Tech Stack

* **Language:** Python
* **Deep Learning:** CNN, TensorFlow/Keras
* **Computer Vision:** OpenCV
* **Libraries:** NumPy, Matplotlib *(add/remove as needed)*



## 🏗️ Project Workflow

1. Data collection and preprocessing

3. CNN model training and validation
4. Real-time traffic sign detection
5. Classification and result visualization
